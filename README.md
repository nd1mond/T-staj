# A/B тест новой формы оплаты ЖКХ

Тестовое задание на стажировку (продуктовая аналитика).

Команда платежей запустила A/B тест новой формы оплаты ЖКХ с автозаполнением реквизитов (1–30 апреля 2024).
Нужно было проанализировать результаты и решить, запускать ли новую форму на всех пользователей.

## Результат

- Доля клиентов, успешно оплативших ЖКХ: **65,5% → 80,4%** (+14,9 п.п.), p-value < 0,001
- Эффект стабильный все 4 недели теста и есть на iOS, Android и во всех городах
- Время оплаты не изменилось

**Рекомендация:** запускать новую форму на всех пользователей.

## Файлы

## Как запустить

1. Загрузить листы `raw_data.xlsx` в PostgreSQL как таблицы `users` и `payments`, выполнить по порядку `01`–`03`.
2. Для ноутбука: `pip install pandas scipy matplotlib openpyxl`, открыть `04_stats.ipynb` и выполнить все ячейки (данные берутся из `ab_data.csv`).

Стек: PostgreSQL, Python (pandas, scipy, matplotlib).
